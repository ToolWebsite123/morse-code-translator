## 2. Public Domain Standards vs. Proprietary Content

To avoid any misunderstanding or overreaching claims, we clearly separate public domain telecommunication standards from our proprietary code and editorial content:

### 2.1 Public Domain Elements (No Ownership Claimed)
- **The International Morse Code Standard:** The alphabet mappings, numeric sequences, standard punctuation marks, procedural signals (prosigns such as SOS `... --- ...`), and timing ratios defined by International Telecommunication Union Recommendation **ITU-R M.1677-1** are universal, historical telecommunication standards residing firmly in the **public domain**.
- **Historical References:** Historical facts, dates, Samuel Morse's telegraphy patents, and Alfred Vail's early code charts are public historical knowledge.
- We make **no proprietary claim of ownership** over standard Morse code dot-and-dash patterns, character tables, or standard telegraphic rhythms.
